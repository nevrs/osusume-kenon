# Chrome ウェブストア 登録用の下書き（おすすめ検温 v0.7.0）

ストアへの登録は、開発者アカウント（初回に 5 ドルの登録料）を持つ本人が、ブラウザで行う。このファイルは、貼り付けるための文面。
zip は `python tools/package.py` で `dist/` に作る（中身は拡張が使うファイルだけ）。

## 名前・短い説明（132 字まで）
- 名前: おすすめ検温
- 短い説明: ストアの「概要」は、zip の中の manifest.json の description から読まれる（管理画面で別に書く欄は無いと思われる。要確認）。いまの manifest の description は次のとおりで、同じ文にしてある: X の「おすすめ」と「フォロー中」の、怒りと敵意の強い投稿の割合を、端末の中で測って比べます
- カテゴリ: 仕事効率化／ツール（どちらか）。言語: 日本語

## 詳しい説明
X（旧 Twitter）の「おすすめ」が、フォローした人の投稿と比べて、どのくらい怒りや敵意の強い投稿を出しているかを、あなたの画面の上で測る拡張機能です。
- 見せられた投稿の本文を、あなたのパソコンの中にだけ残し、Chrome に組み込まれた AI（端末の中）で「怒り」と「敵意」の点を付けます。外部のサーバーへは何も送りません。
- 「おすすめ」と「フォロー中」の差を、設定画面に出します（目安です。アルゴリズムが押し上げた量ではなく、2 つの画面の違いです）。
- 試験機能: 敵意の強い「おすすめ」の投稿を、判定が終わるまで隠し、「たたみました」の札にします。「開く」はあなたが押します。
- すべて、設定でオンにしたときだけ動きます（初期値はオフ）。X のスクロールやボタン押下は、拡張が自動では行いません。
- 判定は誤ることがあります。正当な批判が「怒り」に数えられることもあります。
- 非公式の拡張です。X Corp. とは関係がありません。

## 単一の目的（審査の欄）
X の「おすすめ」と「フォロー中」に出る投稿の、怒り・敵意の強さを端末の中で測り、比べて見せる。

## 権限の理由
- `storage` / `unlimitedStorage`: 記録した投稿の本文と点を、端末の中（chrome.storage.local）に残すため。本文は、14 日を過ぎたものを、X のページか設定画面を次に開いたときに消す。点だけの記録は 1 年で消す。
- ホスト権限（`https://x.com/*` の content script）: X の画面に出た投稿の本文を読み、たたむ札を出すため。

## 個人情報の扱い（プライバシー）
- 外部へ送るもの: なし。外部のサーバーも、分析の仕組みも、使わない。
- 端末の中に残すもの: 見せられた投稿の本文（本文に入っている他人のアカウント名や URL を含む）・「おすすめ」か「フォロー中」か・時刻・判定の点と判定の版（Chrome の主版を含む）・投稿の印。ほかに、判定した件数の日ごとの数、たたんだ件数の日ごとの数、測定モードの開始・終了の時刻、設定のオン・オフ。いずれも端末の中だけ。
- 消し方: 設定画面の「本文だけ消す」「すべて消す」。拡張を削除すれば、すべて消える。
- 判定は、Chrome に組み込まれた AI（Prompt API）だけで行う。
- ストアの「プライバシーへの取り組み」タブにある、扱うデータの種類の申告と、利用制限の遵守の宣誓は、本人が画面で選ぶ。端末の中だけで扱うデータも対象になるかは、Google の現行の規約で確かめていない。本文はウェブサイトのコンテンツに当たるので、そこは正直に選ぶ。
- **プライバシーポリシーの公開 URL が、ストアの登録に要る**。リポは非公開なので、公開する場所（本人のサイトや GitHub Pages など）は、本人が決める。
