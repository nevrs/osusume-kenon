## 点数の式

```
点数 = Σ 重み × その人がその行動をとる確率（予測）
```

## ここから読めること（解釈。X の文言ではない）

1. **返信と引用は、いいねの約 7.6 倍の重み。** 重みは「その行動の確率」に掛かる。怒りの返信も、賛同の返信も、点数の上では同じ「返信」。言い争いに加わりそうな投稿ほど上に来る作り。感情の良し悪しを見る項は、点数の式の中に無い（`toxic` `polariz` `civil` `outrage` は並べ方のコードに見当たらない。見つかったのは不正・スパム・性的な画像の判定の側）。
2. **否定の反応は大きく効くが、学ぶのは「その人の確率」。** 興味がない・ミュート・ブロックの重みは大きいが、掛かる相手は「この人が同じような投稿に興味がないを押す確率」。本人が押した履歴が、その確率を上げる。X 自身もコメントで「報告 1 回でいいね 468 回分が消える、という読み方は誤り」と書いている。
3. **数えられるのは「おすすめ」に出た投稿への行動だけ**（param.rs のコメント 2）。直接開いた投稿への行動は並べ方に入らない。
4. **滞在の重みは小さい**（0.05、見ずに通り過ぎた −0.02）。読み飛ばすだけで変えられる量は小さいと考えられる。ただし予測そのものの入力（行動の履歴）には入る。
5. **相互フォローの相手への返信には大きな上乗せ**（2026-07 に導入、`docs/BIDIRECTIONAL_BOOST_CHANGE.md`）。身内の会話を増やす狙い。対立とは別の向きだが、身内の中の盛り上がりを強める可能性がある。

6. **X は投稿ごとに「広告の隣に置いて危ないか」を判定しているが、その判定は広告を離すことにだけ使う。**
   `home-mixer/models/brand_safety.rs` の `compute_verdict` が、ラベル（Grok による「広告に不適」= `GROK_NSFA`、
   コミュニティノートが付いた投稿 = `NSFA_COMMUNITY_NOTE`、`DO_NOT_AMPLIFY` など）から Safe／LowRisk／MediumRisk／HighRisk を決める。
   使っている場所は `home-mixer/ads/`（広告の上下に置かない）と `filters/ad_adjacent_served_filter.rs` だけ。
   並べ方の点数（scorers）と、表示するかどうかの規則（visibility-filtering）は、この判定を読んでいない。
   危ないと判定された投稿も、点数どおりに並ぶ（`partition_organic_blender.rs` で、広告を置けない投稿を集め、点数で並べ直して戻している）。
   **広告主は守られるが、読む人は守られない**、と読める。ただし Grok が何を「広告に不適」とするかの指示文（Grox の prompt）は公開されていない
   - 別のラベル `DO_NOT_AMPLIFY` は、表示の規則の側で、フォローしていない人へのおすすめから外す（`visibility-filtering/rules/author_rules.rs`・`tweet_rules.rs`）。付ける基準は未読
7. **投稿の埋め込み（似た投稿を探すための数値）は「話題・感情・関心の集まり」で似た投稿を探すよう指示されている**
   （`grox/flows/mm_emb/embedder.py` の `DEFAULT_SYSTEM_PROMPT`）。怒っている投稿の近くには怒っている投稿が来うる（推測）
