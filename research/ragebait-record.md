# 怒りで反応を集める作り（レイジベイト）の判定の記録（DESIGN.md D26）

Chrome 155 の組み込み AI（Prompt API）で、投稿が「読む人を怒らせて反応を集めるように作られているか」を判定させた結果。ローカルのページ（127.0.0.1）から tools/group-probe.js で動かした（X では動かしていない）。集計は tools/ragebait_stats.js。
例文はすべて自作（一から書いた文。実在の投稿・見本の言い回しは使っていない）。各 2 回。

- 合わせ込み用: tools/eval/ragebait.json（40 本。怒らせる作り 20・そうでない 20）。これを見ながら問いを直した
- 確かめ用: tools/eval/ragebait-hold.json（24 本。12・12）。rbs2 を作ったあとで書き、問いを直すときには見ていない。線引き（rbs は 50、rbs2 は 60）は確かめ用を回す前に決めた

AI が作った文かどうかは判定しない（短い文では見分けられず、人の投稿に誤って札を貼ることになる）。誰が書いても同じ手口を見る。

## 問いの版

- **rb1**: 手口を 4 つ（腹の立つ体験談・集団への矛先・言い争いへの誘い・極端な決めつけ）に分け、根拠の言葉を本文から抜き出させる（ev1・ev2 と同じ形）
- **rbs**: 手口に分けず、「読む人を怒らせて反応を集めるように作られている度合い」を 0〜100 の点で聞く
- **rbs2**: rbs に「低くする場合」（公人の具体的な行いへの筋の通った批判・注意を促すお知らせ・答えのある質問・遊びの投票）を足し、いちばん目立つ手口を選択肢から 1 つ選ばせる

## 結果（2026-10-31）

拾えた = 怒らせる作りの例文のうち、AI も付けた数。誤り = そうでない例文に付けた数。2 回の値を並べた。

| 版・線引き | 合わせ込み用 拾えた | 合わせ込み用 誤り | 確かめ用 拾えた | 確かめ用 誤り | 1 件の時間 |
|---|---|---|---|---|---|
| rb1（4 つのどれか） | 13/19・9/18 | 3/20・8/20 | － | － | 約 2.1 秒 |
| rb1（2 つ以上） | 7/19・7/18 | 1/20・0/20 | － | － | |
| rbs 50 以上 | 15/20・17/20 | 1/20・2/20 | **11/12・11/12** | **0/12・1/12** | 約 1.0 秒 |
| rbs2 60 以上 | 19/19・18/20 | 2/20・3/20 | 9/12・9/12 | 0/12・1/12 | 約 1.4 秒 |

- **rb1 は使えない。** 抜き出しが当たらず、極端な決めつけは 2 回とも 0 件。問いの中の項目名（「腹の立つ体験談」など）や説明の文をそのまま書き写す答えが多かった（本文に無いので、コードではじかれる）
- **rbs2 は合わせ込みだった。** 合わせ込み用では良くなったが、確かめ用では rbs より拾えなかった。手口の選択は、ほとんど「言い争いへの誘い」を選び、手口の内訳には使えない
- **rbs を使う（線引き 50）。** 確かめ用で 12 本中 11 本を拾い、誤りは 0〜1 本。いちばん速い
- 外れ続けた例文: 皮肉で真面目に聞くふりをする文（確かめ用。rbs で 25・20）。公人の具体的な発言への落ち着いた批判（合わせ込み用で 70・75、確かめ用で 30・70）は、線引きを越えることがある
- 同じ文でも、回によって点が大きく変わる例文があった（10 と 65 など）

## 実際の投稿で確かめた結果

本人の実際の記録で確かめた結果は、公開のリポには書かない（2026-11-02 の決まり。非公開の dev に置く）。ここには、そこから決めたことだけを書く。

- rbs の点を、そのまま「レイジベイトの割合」として画面に出さない
- 温度の中心は、文の点ではなく反応の形（返信が多め）にする。D25 の「荒れ」（返信がいいね以上）の線は引き直す（DESIGN.md D26。3 段から選ぶ形にする予定）

## 集め方の注意

- 台本は、時間を置かずに回すと同じ投稿ばかりが出て、新しい記録がほとんど増えない。間を空けて回す
- Chrome の窓がほかの窓に完全に隠れると、ページが「隠れた」扱いになり、X の読み込みも止まる。隠れている間は待つ版で動かした
- 英語の画面では、返信 0 件の投稿の返信の数が読めない（数の行の文に出ない）。日本語の画面では読める
- 日本語の画面では、X が外国語の投稿を日本語に訳して出す。記録には訳した文が入るので、「かなが入っている＝日本語の投稿」という見分けは当てにならない
- スクロールの深さで割合が動く（下の基準を参照）。比べるときは件数（始めの何件か）をそろえる

## 「学ぶ前の X」の基準（2026-11-01〜02）

本人が新しく作った X のアカウント（フォローはほぼ無し）のおすすめを、私（Claude）が D21 の台本でスクロールして集めた。そのアカウントの好みをまだ学んでいない X が、何を出してくるかの目安。数を書くのは、AGENTS.md の例外による（本文・投稿者は書かない）。

| 項目 | 値 |
|---|---|
| アカウント | 新しく作ったもの 1 つ（フォローはほぼ無し） |
| 画面の言語 | 日本語 |
| 期間 | 2026-11-01〜2026-11-02（2 日） |
| 集めた件数 | おすすめ 2047 件（反応の数が読めたもの。6 回に分けて集めた。記録の時刻が 3 分以上空いたら別の回と数える） |
| 比べる範囲 | 各回の始めの 150 件（合わせて 458 件） |
| 「返信が多め」（返信 10 件以上で、返信がいいねの 2% 以上） | 始めの 150 件で 33.0%（90% の幅 29.5〜36.7%）。全件では 23.9% |
| 「返信が多め」（返信 10 件以上で、返信がいいねの 3% 以上） | 始めの 150 件で 28.6%（90% の幅 25.3〜32.2%）。全件では 20.2% |

- **始めの 150 件で比べる。** 上のほうほど「返信が多め」が多く、深く進むと減った（600 件より先では、大きい投稿の区間がまた来て少し戻る）。いいねの帯をそろえても減り方は残るので、「上に大きい投稿が来る」ことと「同じ大きさでも上のほうが返信が多め」の両方が効いている。多くの人が見るのは上のほうなので、そこで比べる
- 1 日目と 2 日目の差は小さく、ぶれの幅に収まった。2 日の間で、同じ投稿はほとんど出なかった
- 中身（読んだ範囲。私の分類）: 株のあおり（同じ型の文が、言い回しを少し変えて何本も出る。組織的なものと見る。推測）／外国人・移民への矛先／作り話めいた体験談（身近な場面で理不尽な相手が出てきて、最後にひっくり返る。AI 創作型のレイジベイトに近い形）／書き込みを誘う一言を添えた序列の画像
- いいねの少ない投稿（映画やゲームの宣伝・賭けの勧誘のような、広告らしいもの）も多く混ざる
- 英語の画面でも 1 日目に集めたが、返信 0 件が読めないので基準には使わない
- **限り:** 1 アカウント・2 日・1 つの言語の値。X の出し方は変わるので、日付つきの目安として扱う。基準は日付ごとに 1 つずつ足していく（後から足す基準は別に並べる）
