# 正解の手引き（高温・とげ。DESIGN.md D33。D32 の ②）

いつ読むか: 分類器に覚えさせる作り物の文を書くとき。その文や本人の記録に正解を付けるとき。

- 版: **g1**（2026-11-08）。正解には手引きの版を添える。決まりを変えたら版を上げ、前の版の正解と混ぜない
- 例文はすべて私の自作。実在の人物・団体名は 〇〇・△△ で伏せる（tools/eval と同じ）

## 付けるもの

1 つの投稿に、3 つの印を 0 か 1 で付ける。

| 印 | 1 にするとき |
|---|---|
| intense（高温） | 言葉の選び方が、感情を強く押し出している |
| thorn（とげ） | 実在の人や集団に向けた、敵意の言葉がある |
| grave（重い段） | とげのうち、集団をまるごと見下すもの、または排除・脅し |

- grave が 1 なら、thorn も 1
- intense と thorn は別々に付ける。両方 1 の投稿も、両方 0 の投稿もある
- 印の名前は、コードで「返信が多め」を指す heavy・hot と重ならないものにした

## どの印にも共通の決まり

- **読むのは、その投稿の本文だけ。** 引用された投稿の本文は記録に入らない（record-core.js）。見えない引用元を推し量らない
- **主張が正しいか、どの立場かを問わない**（D15）
- **画像・動画は見えない。** 本文だけで決める
- ハッシュタグは本文の言葉として読む。@名と URL は読まない
- **迷ったら 0。** ev1 の「迷ったら空にする」と、D18 の「出したものが当たっている方を重く見る」に合わせる
- 印は 0 か 1 だけにして、どれだけ強いかは付けない。付ける手間とぶれを減らすため

## 高温（intense）

**1 にする:** 感情を強く押し出す言葉の選び方が、投稿の中心にある。感情の種類（喜び・悲しみ・恐れ・怒り・驚き）は問わない。

手がかり（1 つだけで決めず、全体で読む）:

- 「！」「？！」の連続。「ああああ」のような伸ばしや繰り返し
- 強い言葉・大げさな言い方（「最高すぎる」「人生終わった」「震えた」「地獄」「ありえない」）
- 叫び・すがる言い方（「頼む」「誰か助けて」）
- 笑いや泣きの記号・絵文字・顔文字の連打（「ｗｗｗｗ」「😭😭😭」）

**0 にする:**

- 重い話題でも、落ち着いて書かれたもの。見るのは話題の重さではなく、書き方（D33）
- 感情の言葉や「！」が 1 つ軽く添えてあるだけ（「おいしかった！」「疲れた」）
- 「ｗ」「草」が 1 つだけ
- 呼びかけ・急かしだけ（「伝えてください」「お早めに」）。D15 の「動員」の形でも、強い言い方が無ければ 0（高温は言葉の選び方を見るため）。強い言い方が重なれば 1
- 宣伝の決まった言い方だけ（「本日発売です！」）。宣伝でも、強い言い方が連なれば 1

境目:

| 文 | intense | わけ |
|---|:-:|---|
| 父が亡くなりました。穏やかな最期でした | 0 | 重い話題だが、落ち着いた書き方 |
| 台風の影響で、明日の〇〇便は欠航が決まりました | 0 | 知らせ |
| また止まってる！！！何回目だよ！！もう無理！！ | 1 | 「！」の連続と叫び |
| おいしかった！また行きたい | 0 | 軽く添えた「！」 |
| うますぎて震えた……人生でいちばんのラーメン……！！ | 1 | 大げさな言い方と連続 |
| 合格しました。支えてくれた皆さん、ありがとうございます | 0 | 喜びの話題だが、落ち着いた書き方 |
| 合格したーーー！！！！泣いてる！！！ | 1 | 伸ばし・連続・泣き |
| 続きは明日まとめます。よかったら周りの人にも伝えてください | 0 | 呼びかけだけ |
| 本日発売です！ぜひ手に取ってみてください | 0 | 宣伝の決まった言い方 |
| 今日だけ！！絶対に見逃すな！！急げ！！ | 1 | 宣伝でも、強い言い方が連なる |
| ｗｗｗｗｗｗ腹痛いｗｗｗｗ | 1 | 笑いの連打 |

## とげ（thorn）

**1 にする:** 実在の人や集団に向けて、次のどれかの言葉がある。

- **見下し:** 侮辱する・見下す・人間扱いしない（「バカ」「ゴミ」「虫」「無能」「〇〇脳」）
- **排除:** 追い出す・権利を奪う・黙らせる・社会から消す・暴力を加えることを求める、または当然とする（「出ていけ」「黙らせろ」「選挙権を与えるな」）
- **脅し:** 相手に害を加えると告げる（「覚えてろ」「家を突き止めてやる」）

向けた相手:

| 入る | 入らない |
|---|---|
| 実在の個人（有名人・政治家・知り合い・返信の相手） | 自分（自虐） |
| 実在の人々の集団（国籍・民族・性別・世代・職業・地域・宗教・政治的立場・ある作品のファンなど） | 作品・商品・会社・役所・政党そのもの・制度・機械・AI・物事 |
| 会社や政党などの中の人として罵るもの（「〇〇社の社員はクズ」） | 物語やゲームの登場人物・種族 |

- 役所と政党そのものを外すのは私の判断。ev1 の見下しの問い（feed-judge.js）は、この 2 つを外していない。⑤ で ev1 と並べるとき、ここで差が出うる

**0 にする**（D15・D18・D20 で決めたもの、ev1 の問いで外しているもの）:

- 行い・発言・政策への批判。強い言い方でも、人を罵っていなければ 0（「この判断は最悪だ」。D15）
- 他人の言葉を引用して、批判している・皮肉っているだけ
- ひとまとめにすることを批判する文
- 汚い言葉だけで、向けた相手がいない（「くそ、また負けた」）
- 下品な話
- 本人の選択（「もう〇〇では買わない」「今回は投票しない」）
- 法に沿った処罰の議論（「詐欺をした人は罰を受けるべきだ」）
- 集団の名前が出るだけ（「若者の投票率が上がった」）
- 集団への悪い決めつけだけで、見下しや排除の言葉が無いもの（「〇〇県の人は、みんなせっかちだと思う」）。D18 で、集団の言葉だけは数えないと決めたのに合わせる

### 重い段（grave）

**1 にする:** とげのうち、次のどれか。

- **集団をまるごと見下す:** 集団を指す言葉と、見下しの言葉がそろい、集団の人がみな同じだと語る（今のひとまとめの見下し）
- **排除・脅し:** 相手が一人でも集団でも

一人への見下しだけなら、grave は 0（thorn は 1）。集団の一部だけを見下す文（「〇〇の中には〜もいる」）も、grave は 0。

境目:

| 文 | thorn | grave | わけ |
|---|:-:|:-:|---|
| 〇〇大臣の今日の答弁は、質問に何も答えていなかった | 0 | 0 | 行いへの批判 |
| 〇〇大臣は本当に無能だな | 1 | 0 | 一人への見下し |
| 〇〇党はゴミ | 0 | 0 | 政党そのものへの酷評。行いへの批判と分けにくい |
| 〇〇党に入れる人間は頭が空っぽ | 1 | 1 | 中の人を、集団ごと見下す |
| △△のファンの中には、マナーの悪いクズもいる | 1 | 0 | 集団の一部だけを見下す |
| 「〇〇人は出ていけ」と書く人がいて、悲しくなった | 0 | 0 | 引用して批判している |
| 〇〇県の人は、みんなせっかちだと思う | 0 | 0 | 悪い決めつけだが、見下しや排除の言葉が無い |
| 〇〇県の人間に、この店の敷居をまたがせるな | 1 | 1 | 締め出すことを求める（排除） |
| タクシー運転手は、みんな遠回りして料金を稼ぐ | 0 | 0 | 決めつけだけ |
| タクシー運転手は客にたかるダニだ | 1 | 1 | 集団を人間扱いしない |
| 俺ってほんとポンコツだな | 0 | 0 | 自虐 |
| このゲームのボス、マジでクソ | 0 | 0 | 相手が人でない |
| お前ほんとバカだなｗ 最高 | 0 | 0 | 親しい軽口とも読める。迷ったら 0 |
| あいつを黙らせろ | 1 | 1 | 一人でも、排除は重い段 |
| 家を突き止めてやるからな | 1 | 1 | 一人でも、脅しは重い段 |
| 詐欺をした人は罰を受けるべきだ | 0 | 0 | 法に沿った処罰の議論 |

## 2 つを合わせた例

| | thorn 0 | thorn 1 |
|---|---|---|
| **intense 1** | 合格したーーー！！！！泣いてる！！！ | 〇〇大臣ほんと無能！！！見てるだけで腹立つ！！ |
| **intense 0** | 来週の会議は、場所を 3 階に移します | 〇〇人を、この国に住まわせるべきではないと考えます（grave 1） |

右下（落ち着いた口調のとげ）を落とさない。高温だけを見ていると、ここを見落とす（D33）。

## 作り物の文を書くときの決まり（③ のため）

- 本人の記録や、見本で見た投稿の言い回しを借りない（AGENTS.md）。実在の人物・団体名は 〇〇・△△ で伏せる
- tools/eval の例文にも似せない。あとで確かめに使うと、結果が甘く出るため。この手引きの例文そのものも、③ には入れない
- とげは、左右の立場の言い方を同じ数ずつ入れる（例: 「右寄りの人間は、そろって考える力が無い」と、左右を入れ替えた同じ文）。集団の種類（国籍・性別・世代・職業・地域・宗教・立場）も散らす
- 集団の名前が出るだけの普通の文（thorn 0）を多めに入れる（D32。分類器が「集団の名前があればとげ」と覚えないため）
- 高温は、感情の種類と話題を散らす。怒りに寄せない
- 4 つの組（intense × thorn）が、どれも入るようにする
- 境目の文は、上の表の型ごとに入れる。人でも判断が割れうる文には印（amb）を付ける。学習と確かめでどう扱うかは ③ で決める

## 決めていないこと

- かなを含まない投稿の扱い（D33。⑤ で決める）
- 画面での名前と出し方（D33。⑥ で決める）
