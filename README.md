# おすすめ検温（旧 shizume・鎮め）

> 状態: 試作。動く機能は、設定でオンにしたときだけ動きます（初期値はオフ）: 「送る前の一呼吸」と「見せられた投稿の記録と判定」。測定モードは、あなたがボタンを押した間だけです。オフのあいだ、拡張は X のページで何もしません（実際の X ではまだ確かめていません）。
> 拡張を入れ直したり更新したりしたら、開いている X のタブを開き直してください。

X（旧 Twitter）の「おすすめ」タイムラインは、あなたが**返信や引用をしそうな投稿**ほど上に並べます。
X が公開したコードでは、返信と引用の重みは「いいね」の 7.6〜10 倍です（コードの中に初期値が2つあります）。怒って言い返しても、点数の上では同じ「返信」として数えられます（[調べた記録](research/x-algorithm.md)）。

おすすめ検温は、この仕組みに引き込まれないように手助けする Chrome 拡張です（作成中）。

- **送る前の一呼吸（設定でオンにしたときだけ。初期値はオフ）:** 返信・引用・投稿の下書きが相手を攻撃していると読めるとき、送信を一度だけ止めて、X の仕組みを伝えます。もう一度押せば、そのまま送れます。
  判定は Chrome に組み込まれた AI で行い、下書きは端末の外に出ません。入力をやめてから判定が終わるまで（2〜3 秒）のうちに送ると、止まりません。
  組み込み AI が使えない端末では何もしません
- **見せられた投稿の記録と判定（設定でオンにしたときだけ。初期値はオフ）:** 「おすすめ」「フォロー中」で、投稿の 6 割以上が 0.5 秒以上画面に出ていたものの本文を（画面より背の高い投稿は残りません）、この端末の中にだけ残します。
  残した本文は、X のページを開いている空き時間に、Chrome の組み込み AI（端末の中）が少しずつ読み、「怒り」と「敵意」の点を付けます（1 日 300 件まで）。設定画面に、「敵意が強い投稿の割合」を、おすすめとフォロー中で並べて出します。
  残すのは投稿の印（同じ投稿の二重記録を避けるためのもの）・本文・どちらのタブか・時刻・点です。投稿者名やリンクの欄は残しませんが、本文に入っている他の人のアカウント名や URL は残り、本文から元の投稿はたどれます。
  「フォロー中」に出る自分の投稿も記録されることがあります。X へは何も送らず、画面のスクロールもしません。本文は 14 日で消え（X のページか設定画面を開いたとき）、判定済みの記録は時刻・タブ・点と、投稿の印（ID から作った短い文字列。ID が分かれば照合できます）が 1 年残ります。設定画面から、本文だけ、または全部を消せます
- **測定モード（設定画面のボタン）:** 「おすすめ」と「フォロー中」を、あなた自身がそれぞれ 50 件ぶんほど眺めると、2 つの「敵意が強い投稿の割合」の差を出します。拡張が X のスクロールやタブの切り替えをすることはありません。
  差は「あなたがフォローした人の投稿」と「X が選んで出した投稿」の違いで、アルゴリズムが押し上げた量ではありません。精度は自作の例文での測定で、実際の投稿では外れることがあります（[測った記録](research/anger-record.md)）

- X への操作（興味がない・ミュートなど）を勝手に送ることはしません。押すのは常にあなたです
- 設計の判断と理由: [DESIGN.md](DESIGN.md)

## 設定画面に載せていない細則

- 「強い」は点が 70 以上。判定済みが 30 件に満たない割合は出さない。傾向は直近 14 日。
- 判定は 1 日 300 件まで（測定モードの分は数えない）。判定前の記録は 14 日で消える。判定済みの記録は、時刻・画面の別・2 つの点・投稿の印が 1 年残る。
- 「怒り」には正当な批判も含まれる。判定の精度は自作の例文で測ったもので、実際の投稿では外れることがある（research/anger-record.md）。
- 測定モード: 始める前の記録は数えない。測定中に記録をオフにすると測定も終わる。測定していると分かっていると、見方が普段と変わることがある。
- 組み込み AI が使えない端末では、一呼吸は何もせず、記録だけで判定はされない。
