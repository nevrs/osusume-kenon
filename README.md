# shizume（鎮め）

> 状態: 試作。「送る前の一呼吸」だけが動きます（実際の X ではまだ確かめていません）。

X（旧 Twitter）の「おすすめ」タイムラインは、あなたが**返信や引用をしそうな投稿**ほど上に並べます。
X が公開したコードでは、返信と引用の重みは「いいね」の 7.6〜10 倍です（コードの中に初期値が2つあります）。怒って言い返しても、点数の上では同じ「返信」として数えられます（[調べた記録](research/x-algorithm.md)）。

shizume は、この仕組みに引き込まれないように手助けする Chrome 拡張です（作成中）。

- **送る前の一呼吸:** 返信・引用・投稿の下書きが相手を攻撃していると読めるとき、送信を一度だけ止めて、X の仕組みを伝えます。もう一度押せば、そのまま送れます。
  判定は Chrome に組み込まれた AI で行い、下書きは端末の外に出ません。組み込み AI が使えない端末では何もしません

- X への操作（興味がない・ミュートなど）を勝手に送ることはしません。押すのは常にあなたです
