# shizume（鎮め）

> 状態: 試作。動く機能は、どちらも設定でオンにしたときだけ動きます（初期値はオフ）: 「送る前の一呼吸」と「見せられた投稿の記録」。オフのあいだ、拡張は X のページで何もしません（実際の X ではまだ確かめていません）。
> 拡張を入れ直したり更新したりしたら、開いている X のタブを開き直してください。

X（旧 Twitter）の「おすすめ」タイムラインは、あなたが**返信や引用をしそうな投稿**ほど上に並べます。
X が公開したコードでは、返信と引用の重みは「いいね」の 7.6〜10 倍です（コードの中に初期値が2つあります）。怒って言い返しても、点数の上では同じ「返信」として数えられます（[調べた記録](research/x-algorithm.md)）。

shizume は、この仕組みに引き込まれないように手助けする Chrome 拡張です（作成中）。

- **送る前の一呼吸（設定でオンにしたときだけ。初期値はオフ）:** 返信・引用・投稿の下書きが相手を攻撃していると読めるとき、送信を一度だけ止めて、X の仕組みを伝えます。もう一度押せば、そのまま送れます。
  判定は Chrome に組み込まれた AI で行い、下書きは端末の外に出ません。入力をやめてから判定が終わるまで（2〜3 秒）のうちに送ると、止まりません。
  組み込み AI が使えない端末では何もしません
- **見せられた投稿の記録（設定でオンにしたときだけ。初期値はオフ）:** 「おすすめ」「フォロー中」で画面に 1 秒以上出ていた投稿の本文を、この端末の中にだけ残します。
  あとで「怒りや敵意の強い投稿がどれだけ流れてきたか」を調べるためのものです（調べる部分はまだありません）。
  残すのは投稿の印（同じ投稿の二重記録を避けるためのもの）・本文・どちらのタブか・時刻です。投稿者名やリンクの欄は残しませんが、本文に入っている他の人のアカウント名や URL は残り、本文から元の投稿はたどれます。
  「フォロー中」に出る自分の投稿も記録されることがあります。X へは何も送らず、画面のスクロールもしません。14 日で消え（X のページか設定画面を開いたとき）、設定画面から全部消せます

- X への操作（興味がない・ミュートなど）を勝手に送ることはしません。押すのは常にあなたです
