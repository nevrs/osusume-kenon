# shizume（鎮め）

> 状態: 設計中。まだ動くものはありません。

X（旧 Twitter）の「おすすめ」タイムラインは、あなたが**返信や引用をしそうな投稿**ほど上に並べます。
X が公開したコードでは、返信と引用の重みは「いいね」の約 7.6 倍です。怒って言い返しても、点数の上では同じ「返信」として数えられます（[調べた記録](research/x-algorithm.md)）。

shizume は、この仕組みに引き込まれないように手助けする Chrome 拡張です（作成中）。

- X への操作（興味がない・ミュートなど）を勝手に送ることはしません。押すのは常にあなたです
- 設計の判断と理由: [DESIGN.md](DESIGN.md)
